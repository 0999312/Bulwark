# 枪械手感与配件系统备忘（M0 后设计意向）

> 状态：意向记录，非实现计划。来源：开发者口述（2026-08）。
> 关联文档：`game-design-doc.md`（§6.2 两级武器设计）、`architecture-design.md`（WeaponModelData / WeaponTypeData）。

## 1. 意向摘要

1. **改枪机制**：局外（战前装配）甚至局内（战斗中调整）的武器配件修改，参考搜打撤类游戏（《逃离鸭科夫》Escape from Duckov 等）。
2. **射击手感**：学习《逃离鸭科夫》的可感知后坐力与散布，但需适配 2D 俯视角。
3. **交战距离约束**：本游戏大部分是近距离交战，中距离都少——狙击镜等远距瞄具设计需谨慎，勿按 FPS 长枪交火逻辑做。

## 2. 交战距离实证（M0 数据）

| 数据 | 值 | 来源 |
|---|---|---|
| 战场 | 2200 × 1800 | `game_session.gd` NAV_RECT |
| 刷怪点 | 距基地 720 环形外沿 | `main.tscn` SpawnPoints |
| 敌人速度 | 115 px/s | `enemy_runner.tres` |
| 敌人攻击距离 | 70 | 同上 |
| 步枪射程 / 手枪射程 | 900 / 600 | `model_storm7.tres` / `model_sentinel1.tres` |
| 玩家速度 | 260 | `game_session.gd` |

**结论**：敌人目标为基地（静止圆心），玩家防守时交火实际发生在基地 200–500 半径内；即使主动前出拦截，敌人 6 秒跑到基地，玩家通常没有拉出中远距离交火的时间窗。**高倍镜是负资产**（开镜视野收窄、近距目标脱靶）。瞄具设计应偏向：无镜腰射（默认）、红点/全息（小幅精度加成，无倍率惩罚）、狙击镜若做，定位为"防守预警期远距点名"的可选配件而非主力玩法。

## 3. 2D 俯视角的射击手感模型（鸭科夫参考，2D 适配）

FPS 的后坐感 = 枪口上跳（屏幕 Y）+ 准星与枪口分离 + 屏幕震动。2D 俯视角没有"上跳"，对应物是：

| FPS 概念 | 2D 俯视角等价物 |
|---|---|
| 枪口上跳 | **瞄准点随机偏移**：每发子弹后 aim 方向施加脉冲偏移，弹簧恢复（recoil 值 = 脉冲强度） |
| 准星扩散（bloom） | **散布角**：连射中 spread 持续扩大、停火收缩；移动时基础散布加大 |
| 枪口火焰/烟尘 | 枪口粒子 + 弹壳（可省） |
| 屏幕震动 | Camera2D shake（小幅度、方向 = 后坐脉冲反方向） |
| 腰射 vs 开镜精度 | 无镜状态散布大；瞄具配件缩小散布角 |

**手感数值草案**（M0 后调参起点，单位：度/发）：

- 基础散布角 0.5°，连射每发 +0.15°，上限 4°，停火每秒 -3°
- 后坐脉冲每发 0.6°，恢复速度 3°/s（弹簧）
- 移动散布 ×1.5
- 屏幕震动幅度 2–4px，时长 60–100ms，仅连射时

**弹道模式注意**：`WeaponTypeData.BallisticMode` 已预留 HITSCAN / PROJECTILE / SPREAD 等 8 种；散射型武器（霰弹）直接发多弹道，散布机制统一挂在"每发子弹"层。

## 4. 改枪/配件系统的架构切入点

现有两级设计已为配件预留接缝：

- **WeaponTypeData（种类）**：手感/定位/弹药/弹道/切换 CD。已含 `recoil: Vector2`（后座手感，M0 未参与结算）。
- **WeaponModelData（型号）**：数值（伤害/射速/弹匣/换弹/`spread`/暴击）+ `keywords` 词条列表（架构文档已预留穿甲/燃烧/扩容等）。
- **AttributeSet**：base + additive + multiplicative 修正通道，天然可承载配件加成（M1 商店/技能已规划复用）。

**建议形态**（实现时再定稿）：

1. 配件 = Resource（`AttachmentData`）：槽位（枪口/瞄具/握把/弹匣/枪托…）、修正列表（`AttributeSet` 式 add/mul）、词条追加（keywords）、视觉（枪口特效/准星样式）。
2. 装配 = 局外（`WeaponSlots` 装配快照）+ 局内（战斗中可换，占切换 CD 或独立动作）两阶段共用同一修正管道。
3. 结算 = `DamagePipeline` 已是纯函数，配件修正只影响入口数值（伤害/散布/后坐/弹匣），不动管线本身。

## 5. 待定问题（实现前确认）

- 配件来源：商店购买（M1 波间商店）？搜刮掉落？局内改装是否需要时间惩罚？
- 鸭科夫式"枪械耐久/卡壳"是否引入（建议原型阶段不做，负面体验风险高）。
- 狙击镜如果做，是"高伤害低射速长射程"的枪械词条，还是独立瞄具槽位？
- 后坐力是否需要"压枪"操作（玩家输入抵消），还是纯表现（自动恢复）？原型建议先做纯表现，验证手感后再决定。
