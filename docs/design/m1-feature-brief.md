# M1 核心循环开发 · 功能需求单（Feature Brief）

> 状态：**M1 已实现并通过验收（2026-08，GUT 160/160）** · 关联：`game-design-doc.md`（§17 里程碑表）、`architecture-design.md`（§4/§5/§8）、`gunplay-attachment-notes.md`（改枪/手感意向）
> 用途：M1 开发验收依据 + M2 交接存档。开发者拍板项均回填（见 §5 决策记录）。

## 1. 目标

M0 可玩闭环（103 测试）之上完成 M1 核心循环：**单局 15 分钟可玩**——
三槽武器完整（副武器霰弹枪）、波间基地商店、路障防线、复活系统、改枪配件 MVP、
鸭科夫式 2D 射击手感、奔跑者变种构成的波次系统。

## 2. M0 遗留修复（优先）

1. **射击手感调参**：按 `gunplay-attachment-notes.md §3` 的 2D 模型实现——
   后坐（瞄准点脉冲偏移 + 弹簧恢复）、散布 bloom（连射扩散/停火收缩/移动加成）、
   方向化相机震动；参数集中在 `player_view.gd` 顶部常量区 + `model_*.tres`。
2. **敌人"小怪感"**：变种视觉（体型/颜色）、受击闪白、死亡粒子反馈；
   不新增敌人类型（开发者拍板：前期只有奔跑者变种）。

## 3. M1 功能清单

| # | 功能 | 说明 | 验收要点 |
|---|------|------|----------|
| F1 | 副武器霰弹枪 | 类型（SUB/SPREAD）+ 型号"裂齿"（pellets=6） | 2 键切换 1.5s CD、扇形多弹道、近距离压制 |
| F2 | 波间基地商店 | 每波清场刷新 4 随机 + 固定物资（路障/储备） | 价格 `base×rarity×1.3^n` 递增；暂停树打开 |
| F3 | 货币经济 | 击杀奖励（EnemyData.kill_reward）+ 概率建材 | RunState 统一持有，事件驱动 HUD |
| F4 | 路障 | E 键放置（建材消耗、基地 build_radius 内）、碰撞阻挡、敌人优先攻击 | 路障耐久归零摧毁；被挡敌人攻路障不啃基地 |
| F5 | 复活系统 | 应急储备自动复活 + 复活 CD（4s）；储备耗尽判负 | P7/P20；复活回基地满血；CD 中敌人继续进攻 |
| F6 | 配件系统 MVP | AttachmentData（枪口/瞄具/弹匣/枪托 4 槽）+ 商店购买 + 局内装配 UI | WeaponStats 结算：模型×配件×全局强化；词条合并 |
| F7 | 波次构成扩展 | WaveData 多敌人组（WaveSpawnGroupData）；奔跑者变种（疾行者/硬壳者）；波次 4~6 | 同种子确定性保持；HUD 只报方位 |

## 4. 非目标（M1 明确不做）

- 新敌人类型（自爆体/喷吐者等）、精英波、Boss —— M3/M4
- 搜索循环、时间压力、掉落表 —— M3
- 多人联机、meta 存档 —— M2/M4
- 技能系统、狙击镜/高倍瞄具（SIGHT 槽仅红点类无倍率配件）
- 枪械耐久/卡壳、压枪操作（纯表现自动恢复）

## 5. M1 决策记录（开发者拍板，已回填 gunplay-attachment-notes.md）

| # | 决策 | 结论 |
|---|------|------|
| M1-D1 | 配件系统深度 | 完整 MVP：数据+商店+装配 UI（背包→装备当前武器对应槽） |
| M1-D2 | 敌人构成 | 不加新敌人；奔跑者变种（数据配置）丰富构成 |
| M1-D3 | 复活交互 | 自动复活 + 复活 CD（4s），储备耗尽才判负 |
| M1-D4 | 配件来源 | 波间商店购买；局内装配无时间惩罚 |
| M1-D5 | 瞄具设计 | 不做倍率镜；SIGHT = 红点类精度配件；狙击武器入扩展池 |
| M1-D6 | 路障碰撞 | layer 8（world），敌人 mask 含 8；玩家不受阻挡 |

## 6. 架构约束（继承 M0，硬性）

1. Registry + ResourceLocation（bulwark: 命名空间），新增 3 注册表（attachment/shop_item/facility）
2. 前后端分离：`scripts/core/` 无 get_node/渲染引用；表现层只读状态+发意图
3. 数据驱动：配件/商品/设施/变种 = Resource
4. 不修改 `addons/` 第三方插件

## 7. 测试策略

- 单元（新增）：RunState、ShopSystem（刷新/递增/购买）、ReviveSystem（CD/储备）、
  BarricadeController（耐久/路由）、WeaponStats（修正管道）、WeaponSlots 配件装配、
  WaveGenerator 多组、内容注册 M1 条目
- 集成（新增）：M1 会话装配（经济/路障/复活/商店流程/配件背包）
- 回归：M0 全部 103 测试不回归
